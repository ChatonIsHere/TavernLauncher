# Base Requirements

## Getting the game files

To be able to play the game, you need a functioning copy of the LATEST build of A Township Tale. We do not distribute these
files. If you no longer have access to your copy of the game, you are free to ask the community for help. Do NOT ask staff
for this as we do not assist with this for obvious legal reasons.

If you are uncertain whether you have them, the location of installation is this one by default: <br>
`C:\Games\Alta\A Township Tale\` <br>
Make sure that this executable is inside of that folder: "A Township Tale.exe"

The latest game version that Alta made is the following: <br>
`main-1.7.2.1.42203`

### Backups

Before following this guide - it is a good idea to make a backup of your game files in case you mess up at any point. Makes rolling back a
lot easier down the line!
