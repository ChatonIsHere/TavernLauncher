# Introduction

Welcome to the tutorial for The Modding Tavern.
This documentation serves as your point of reference for setting up your very own server, or joining an existing one.
It also contains a section for the most commonly asked questions.
Please read this if you are having trouble before asking for help on Discord as the information will likely be the same!

This guide covers only SteamVR!
The Modding Tavern is a framework built only for SteamVR at this time and Quest is being looked at separately.
Quest will work very different so to enjoy the most of the additional features that the community builds (mods), we highly
suggest using SteamVR.

Please note that this project has been made as a way for the community to play their beloved game again. We believe that none of this
information should be confidential and accessable to every one. For this reason this whole project was made as an open source project
where anyone can contribute to it.

Please choose your desired outcome, or read the TLDR versions if you are a technical person: <br>
- [Joining a server](page:joining-full) -> [TLDR](page:joining-tldr) <br>
- [Setting up a local server for yourself](page:local-server-full) -> [TLDR](page:local-server-tldr) <br>
- [Setting up a public server for yourself](page:public-server-full) -> [TLDR](page:public-server-tldr)

If you believe you've gone through all the setup steps and are still unable to join/host a server, please
visit the [FAQ](page:faq) or attempt to [troubleshoot](page:troubleshooting) the problem yourself.

If you're looking for more information about inner workings, please visit the [technical documentation](page:technical-docs).
